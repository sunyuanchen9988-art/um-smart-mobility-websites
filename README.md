# UM Smart Mobility Websites

This repository contains two bilingual static demo websites for the UM Zero-Emission Smart Campus Mobility Ecosystem proposal.

## Sites

- Stakeholder Portal: `stakeholder-portal/index.html`
- UM Mobility App Website: `um-mobility-app/index.html`
- Root entry page: `index.html`

## GitHub Pages

To publish the website:

1. Open repository Settings.
2. Go to Pages.
3. Source: Deploy from a branch.
4. Branch: `main`.
5. Folder: `/root`.
6. Save.

After GitHub finishes deployment, the site should be available at:

`https://sunyuanchen9988-art.github.io/um-smart-mobility-websites/`
