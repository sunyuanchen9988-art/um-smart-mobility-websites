Project Definition

Project Command Dashboard

A structured summary of the project definition, scope and delivery logic for the UM Green Mobility Project.

Project Type

Zero-Emission Smart Campus Mobility

Client Context

Universiti Malaya

Core System

Eight-layer mobility ecosystem

Delivery Logic

Hybrid delivery + PMIS monitoring

Background

UM faces growing pressure from private vehicle use, parking demand, gate congestion and fragmented internal mobility.

Scope

The project covers demand management, active mobility, electric shuttle services, energy systems, Mobility Hubs, digital platforms and governance.

Objectives

To deliver a low-emission, user-centred and financially justified campus mobility transformation.

Problem Context

UM Mobility Challenges & PESTEL Snapshot

This section summarises the key campus mobility problems and the external factors that shape the proposed green mobility response.

UM Mobility Challenges

Campus problem map

01 Private Vehicle Dependence

High reliance on private vehicles increases internal circulation pressure.

02 Parking Pressure

Limited parking capacity increases search traffic and access stress.

03 Gate Congestion

Peak-period flows create pressure at campus access points.

04 Traffic Emissions

Vehicle movement contributes to carbon and local air-quality impacts.

05 Tropical Climate

Heat and rainfall reduce walking and cycling comfort.

06 Complex User Scenarios

Students, staff, visitors, UMMC users and accessibility users need different mobility responses.
